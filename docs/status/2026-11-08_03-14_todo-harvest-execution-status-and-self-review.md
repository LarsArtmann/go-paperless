## e) WHAT WE SHOULD IMPROVE

1. **Lint-config before first line.** New functions in this repo must be sized for gocognit ≤ 25 from the start; check `.golangci.yml` when touching a file class I haven't written here before.
2. **Targeted-lint first, full gate last.** `buildflow -s golangci-lint` (or the repo's `nix run .#lint`) on the touched file catches complexity/style in seconds; `nix run .#check` is the closer, not the prober.
3. **Ban wholesale appends.** File merges happen via edit-with-exact-anchors; heredocs only create brand-new files; python truncation only with a content-anchored (never line-numbered) cut.
4. **Living docs get verified claims only.** "Tool X covers Y" needs the tool's own output behind it before it enters TODO_LIST/AGENTS (d-5); "gate fails because Z" needs the finding list (d-6).
5. **Negative-verify every new guard same-session** (d-8): inject the drift, watch it fail, revert. It is 30 seconds and it converts an assertion into evidence.
6. **Diagnose before attributing** (d-6): read the failing gate's findings; check for per-repo config (`.docs-gates.json`) before interpreting thresholds as immutable.
7. **Sibling-repo edits get sibling-repo verification:** `git -C <repo> status` after any cross-repo touch, even comment-only ones (b-4).
8. **Daemon coexistence discipline:** `git log -1` before ANY history-touching op, `git status` before heredoc/append-style work, and expect the tree to be committed mid-edit — keep every intermediate state parseable (this session's d-2 breakage would have been invisible to the daemon if the append had been two safe edits).
9. **Restart the LSP once its documented causes are fixed** instead of carrying phantom diagnostics all session (b-6) — the AGENTS.md recovery order exists precisely for this.
10. **"Leave to ROADMAP" is a routing claim:** open ROADMAP.md and confirm the parked home before closing a harvest decision (b-1).
11. **Correct inherited plans when they're impossible** — the one thing this session got right end-to-end: the f-11 "20ms hint" suggestion was physically impossible under whole-second parsing, and the fix changed the test's shape instead of implementing a fantasy. Do more of that.
